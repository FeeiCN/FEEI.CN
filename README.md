## 这是什么

**一个长期公开沉淀的判断与方法论系统。**

它用文档、数据和复盘记录一个人如何在健康、事业、财富和人生体验上持续做选择。网络空间安全是长期主线，其他方向是同一个问题的延伸：如何在不确定环境里，建立更稳定的判断和行动系统。

| 方向 | 一句话 | 入口 |
| :--- | :--- | :--- |
| **健康幸福** | 把身体、心理、关系当作长期系统 | [/health](https://feei.cn/health) |
| **事业有成** | 把自我塑造成能持续做值得做的事的状态 | [/capability](https://feei.cn/capability) |
| **财务自由** | 把今天的收入转化为未来的选择权 | [/wealth](https://feei.cn/wealth) |
| **人生丰富** | 在效率之外保持对世界的好奇 | [/experience](https://feei.cn/experience) |

## 适合谁

这个仓库更适合想观察一个长期个人系统如何被持续维护的人：

| 如果你想看 | 这里能提供 |
| :--- | :--- |
| 个人知识库如何组织 | 主题分层、入口页、长期文档和年度复盘 |
| 数据如何进入个人决策 | 阅读、健康、资产、AI 使用等数据仪表盘 |

它不适合被当作通用博客模板、理财/健康建议库或可直接复用的数据同步系统。这里的结论来自个人经历和个人约束，真正有价值的是背后的记录方式和判断过程。

## 这一切为什么开始

有一天，对着镜子，看到的是一个自己不喜欢的自己：身体浮肿、精力下降，体检报告上的异常指标越来越多。

债务压力、健康焦虑、能力增长变慢、身边人遭遇职业波动，这些事情叠在一起，让“还行”变成了最危险的状态。

**"还行"才是最让人停滞的陷阱。**

于是开始反问自己：到底在追求什么？想要的，是能穿越短期波动和偶然运气的东西，是在复杂变化中依然能一点点建立起来的确定性。

这个站点，就是那次反问之后的回答。

## 数据边界

这个仓库包含公开展示所需的数据和页面代码，也包含一些自动同步脚本。健康、阅读、资产、LLM 用量等数据用于个人复盘和站点展示，不代表通用模板，也不保证适合外部直接运行。

部分脚本依赖本机私有环境、GitHub Variables、iPhone App 或个人账号授权。公开仓库只保留可审计的代码和结构化输出，不包含运行这些同步链路所需的私有凭证。

## 本地运行

```bash
git clone https://github.com/FeeiCN/FEEI.CN.git
cd FEEI.CN
npm install
npm run start          # 本地开发，http://localhost:3000
```

构建与检查：

```bash
npm run build          # 生产构建到 build/
npm run typecheck      # TypeScript 严格类型检查
npm run serve          # 本地预览构建产物
```

要求：Node.js `>= 20`。

## 目录速查

```
docs/         全部内容（300+ 篇 .md / .mdx，按方向分目录）
src/
  components/  自定义 React 组件、仪表盘与图表
  pages/       首页与自定义页面
  theme/       Docusaurus 主题覆盖
  css/         全局样式
plugins/       自研 Docusaurus 插件（docMtimePlugin）
scripts/       数据同步脚本（健康/阅读/LLM）
static/        静态资源（图片/音乐/媒体/结构化数据）
  data/        JSON 等结构化数据（阅读/健康/地图/资产/港股打新/LLM 用量）
```

大体积媒体资源不全部进入 Git。文章正文使用 `/media/...` 路径引用，相关同步配置见 `config/media-rsync.env.example` 与 `ops/media-rsync/`。
