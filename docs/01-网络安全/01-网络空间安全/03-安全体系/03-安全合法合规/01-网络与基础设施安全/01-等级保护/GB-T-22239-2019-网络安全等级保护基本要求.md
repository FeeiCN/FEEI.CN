# GB/T 22239-2019 网络安全等级保护基本要求

本标准是等级保护2.0的核心控制基线，2019-12-01实施，当前现行。

## 核心框架

标准采用**安全通用要求 + 安全扩展要求**。通用要求覆盖安全物理环境、安全通信网络、安全区域边界、安全计算环境、安全管理中心，以及制度、机构、人员、建设和运维等管理要求；云计算、移动互联、物联网、工业控制等场景叠加适用扩展要求。

## 落实与验收

- 建立“标准条款 → 系统资产 → 技术/管理控制 → 责任人 → 证据”的控制矩阵。
- 不以测评报告代替日常运行；身份权限、边界防护、日志审计、恶意代码防范、备份恢复等应能从真实配置和运行记录验证。
- 架构变化、新技术形态或系统边界变化后重新判断扩展要求。

**验收标准：**从生产资产和账号反查控制覆盖；随机抽测关键配置和日志；测评问题有整改、复测或正式风险接受；制度描述与真实技术实现一致。
