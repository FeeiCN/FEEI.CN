# 支付与金融安全

金融合规首先按**主体和业务牌照**判断，再叠加网络、数据、密码、事件和反诈要求。不能把“金融行业要求”理解成一套统一规则。

## 主体判断

| 主体/场景 | 优先进入 |
| --- | --- |
| 非银行支付机构 | 监督管理条例、实施细则、分类评级及人民银行专项规则 |
| 人民银行监管对象 | 人民银行数据安全、网络安全事件报告等适用要求 |
| 银行保险机构 | 银行保险数据安全及信息科技风险要求 |
| 涉及电诈风险 | 反电信网络诈骗法中的金融主体义务 |
| 金融系统建设 | 同时判断等保、密评、关基及金融行业技术标准 |

## 企业落地

支付/金融主体更适合维护一张**监管义务矩阵**：监管文件 → 适用主体 → 业务/系统 → 控制责任人 → 证据 → 报告对象/时限。网络与基础设施通用制度统一链接到[网络与基础设施安全](../01-网络与基础设施安全/index.md)，避免在本域重复建设。
