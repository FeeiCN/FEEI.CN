# 平台App与AI

这一域按**服务能力**判断，而不是按公司标签判断。一个App同时提供算法推荐、生成式AI和拟人化互动时，可能并行命中多套规则。

## 上线检查

新功能上线前至少判断：**服务对象、内容生成方式、算法机制、个人信息、未成年人、备案/登记/标识要求、投诉处置、内容安全和事件响应**。同一能力命中多个规则时统一建设底层控制，不分别复制审核、日志和应急流程。

个人信息基础规则统一进入[数据与隐私安全](../02-数据与隐私安全/index.md)。
