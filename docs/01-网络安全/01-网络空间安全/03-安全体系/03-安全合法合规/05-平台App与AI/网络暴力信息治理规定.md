# 网络暴力信息治理规定

## 法规概览

| 项目 | 内容 |
| --- | --- |
| 发布 | 国家网信办等四部门令第17号 |
| 施行 | 2024年8月1日 |
| 重点主体 | 网络信息服务提供者 |

## 安全要求与实施

### 建立网络暴力识别和预警机制

**落实与验收。** 将侮辱谩骂、造谣诽谤、侵犯隐私、贬低歧视等风险纳入内容分类和异常传播监测，对短时间集中攻击、异常评论和跨账号围攻及时预警。

**验收证据。** 从真实热点事件反查平台何时首次发现集中攻击，是否在用户投诉前已有异常信号。

### 保护受害者并限制传播放大

**落实与验收。** 提供防护、私信/评论限制、举报投诉等能力；推荐、热搜、榜单等机制不得主动放大网络暴力内容。

**验收证据。** 模拟用户遭集中攻击，验证一键防护、举报、屏蔽、推荐降权是否真实有效。

### 管理账号、群组和MCN等组织化行为

**落实与验收。** 对组织煽动、批量账号、群组围攻和利用网络暴力牟利建立关联识别与处置，不只删除单条内容。

**验收证据。** 从一条已处置内容反查关联账号、群组和传播链，确认是否存在“删帖不治链”。

### 保存处置证据并支持投诉举报

**落实与验收。** 保存原始内容、传播范围、账号关系、处置动作和时间线，投诉处理可追溯。

**验收证据。** 内容删除后仍能否重建事实和处置依据。
