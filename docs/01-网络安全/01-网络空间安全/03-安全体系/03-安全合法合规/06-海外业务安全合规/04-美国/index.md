# 美国

美国不适合用一篇“美国网络安全法”概括。支付业务应至少分为**联邦金融/隐私要求、州隐私与数据泄露规则、州Money Transmitter监管、特定州金融网络安全规则、制裁与AML**。

后续按实际经营州和牌照范围增加独立监管页面，避免在业务尚未进入某州时维护一套失真的“全国统一要求”。
