# 行业专项

行业专项不是“其他法规”收纳箱。只有**某一行业在通用网络、数据、个人信息制度之外存在明显专项要求**时才进入这里。

当前收录：

- [汽车数据安全管理若干规定](./汽车数据安全管理若干规定.md)：汽车数据处理活动的专项要求。

新增行业前先判断是否已经属于支付金融、平台App与AI或海外业务，避免重复分类。
