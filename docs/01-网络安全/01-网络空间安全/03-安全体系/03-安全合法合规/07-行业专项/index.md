# 行业专项

行业专项不是“其他法规”收纳箱。只有**某一行业在通用网络、数据、个人信息制度之外存在明显专项要求**时才进入这里。

当前收录：

- [汽车数据安全管理若干规定](./汽车数据安全管理若干规定.md)：汽车数据处理活动的专项要求。

新增行业前先判断是否已经属于支付金融、平台App与AI或海外业务，避免重复分类。

## 收录标准

新增一个行业专题前至少满足两个条件：

1. 存在通用网络、数据、个人信息制度之外的明确行业专项义务；
2. 能形成独立的**适用主体 → 业务/数据对象 → 专项控制 → 监管/报告 → 验收证据**链路。

否则继续放在原治理域，通过标签或交叉链接表达行业适用性，避免把本目录变成“其他”。
