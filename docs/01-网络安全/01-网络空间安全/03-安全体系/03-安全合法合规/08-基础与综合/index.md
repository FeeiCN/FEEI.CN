# 基础与综合

这里不是“暂时不知道放哪”的目录，而只保存**跨多个治理域的上位或综合性依据**。

当前核心文件：

- [国家安全法](./国家安全法.md)：国家安全总体制度，与网络、数据、关基、审查等安全制度存在上位背景关系。

具体网络、数据、支付、平台或行业规则仍放回各自治理域，避免本目录继续膨胀。

## 使用边界

阅读这里的文件时，重点理解其对专项制度的**背景、原则和法律依据**。具体企业控制、测评、报告和检查要求仍回到对应治理域落实；不要从综合性法律直接推导一套与专项制度重复的控制清单。
