# 产品与方案认证检测

产品层应先判断是否进入法定目录或采购方指定标准。国内重点区分网络关键设备/网络安全专用产品的认证或检测、商用密码产品认证；国际还常见CC、FIPS以及PCI PTS/P2PE/Secure Software等。

## 判断字段

统一记录：**对象、类型、地域、触发条件、主管/规则机构、周期或有效期、官方查询入口、最终证据、关联控制**。只有命中实际业务或监管需求时，才继续建立具体认证/资质页面。
