# 产品与方案认证检测

### 网络关键设备和网络安全专用产品

列入现行目录的产品，应按照相关强制性国家标准，经具备资格的机构**安全认证合格或者安全检测符合要求**后方可销售或者提供。现行制度不是简单沿用旧的“安全专用产品销售许可证”概念。

2023年调整后的目录包括网络关键设备（如达到门槛的路由器、交换机、服务器、PLC）和防火墙、IDS/IPS、数据备份恢复等网络安全专用产品。认证按CNCA-CCIS-2023规则实施；认证/检测结果由官方统一发布并可查询。

### 商用密码产品认证

纳入商用密码产品认证目录的产品按照相应认证规则和技术标准开展认证。2025年市场监管总局、国家密码管理局发布第三批目录，继续扩展SM9密钥管理、PLC密码模块、DTLCP、SSH密码模块等产品范围。

### 国际安全产品评价

| 项目 | 对象 | 主要价值 |
| --- | --- | --- |
| Common Criteria / ISO/IEC 15408 | IT安全产品 | 对安全功能和保障能力进行标准化评价，常用于政府、关键行业采购 |
| FIPS 140-3 / CMVP | 密码模块 | 美国/加拿大密码模块验证生态，政府及供应链常见 |
| FedRAMP | 美国联邦云服务 | 云服务面向美国联邦机构的授权体系，并非普通产品认证 |

### PCI产品与方案

| PCI体系 | 对象 |
| --- | --- |
| PCI PTS POI | POS、PIN输入等支付交互设备 |
| PCI PTS HSM | 支付HSM |
| PCI P2PE | 点到点加密Solution、Component、Application |
| PCI Secure Software | 支付软件产品 |
| PCI Secure SLC | 支付软件厂商的软件安全生命周期 |
| PCI MPoC | 移动设备上的支付受理解决方案 |

PA-DSS已经退役，由Secure Software和Secure SLC体系承接；选择产品时应核对PCI SSC官方listing中的具体产品、版本和有效状态。
