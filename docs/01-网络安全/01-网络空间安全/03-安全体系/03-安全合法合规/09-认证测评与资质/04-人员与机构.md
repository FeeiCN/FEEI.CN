# 人员与专业机构资质

### 国内

| 项目 | 侧重点 | 备注 |
| --- | --- | --- |
| CISP | 综合信息安全专业能力 | 国内较常见的人员能力认证 |
| CISP-PTE等方向 | 渗透测试等专项能力 | 按岗位价值判断，不是企业法定合规证明 |
| 等保测评相关人员/测评机构能力 | 等级保护测评 | 应区分机构能力要求与个人培训证书 |
| 密评从业人员/密评机构 | 商用密码应用安全性评估 | 属于密评专业实施能力体系 |

### 国际

| 项目 | 侧重点 |
| --- | --- |
| CISSP | 综合安全架构与管理 |
| CISM | 安全管理与治理 |
| CISA | IT审计 |
| CCSP | 云安全 |
| OSCP / OSCE³ | 攻防与渗透测试 |
| GIAC系列 | 细分安全技术领域 |
| PCI QSA | PCI DSS第三方评估专业资格体系 |
| PCI ISA | 企业内部PCI安全评估人员 |
| P2PE Assessor | PCI P2PE独立评估 |

人员证书主要证明个人知识、经验或专项能力，不能替代企业、系统或产品必须完成的认证和测评。
