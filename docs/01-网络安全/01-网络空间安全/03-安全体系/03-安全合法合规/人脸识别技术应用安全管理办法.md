# 人脸识别技术应用安全管理办法

## 法规概览

| 项目 | 内容 |
| --- | --- |
| 发布 | 国家网信办、公安部令第19号 |
| 施行 | 2025年6月1日 |
| 核心对象 | 应用人脸识别技术处理人脸信息的个人信息处理者 |
| 关键阈值 | 存储人脸信息达到10万人后30个工作日内备案 |

## 安全要求与实施

### 先证明必要性而不是先部署人脸

**法规要求｜第4—7条。** 应具有特定目的和充分必要性，采取权益影响最小方式；基于同意处理时取得单独同意，未成年人适用更严格规则。

**落实与验收。** 上线前形成必要性和替代方案评估；能够使用密码、卡证等非人脸方式达到目的时，不默认强制人脸。

**验收证据。** 问产品负责人：不用人脸是否真的无法实现目的？是否给用户提供同等可用替代方式？

### 默认本地、最短保存和最小传输

**法规要求｜第8条等。** 原则上人脸信息存储于识别设备内，不通过互联网对外传输；保存期限不得超过必要最短时间，法定例外或单独同意除外。

**落实与验收。** 车端/门禁/终端优先本地比对；云端上传必须单独识别依据并限制保存。

**验收证据。** 抓取设备网络流量验证是否实际上传人脸模板或原图；检查备份、日志和第三方是否形成额外副本。

### 达到10万人及时备案

**法规要求｜第15条。** 存储数量达到10万人之日起30个工作日内备案；实质变更和终止也有30个工作日变更/注销要求。

**落实与验收。** 人数统计自动化，接近阈值提前预警；备案范围与生产实际持续对账。

**验收证据。** 从生产库复算人数、首次达到阈值日期和备案日期。

### 技术安全必须真实有效

**法规要求｜第14条。** 采取加密、安全审计、访问控制、授权管理、入侵检测防御等措施，并叠加等保、关基要求。

**验收证据。** 随机抽管理员、接口、密钥、导出和删除链路，验证最小权限、审计和删除真实有效。
