# 国家网络身份认证公共服务管理办法

## 法规概览

| 项目 | 内容 |
| --- | --- |
| 发布 | 公安部等六部门令第173号 |
| 施行 | 2025年7月15日 |
| 核心机制 | 网号、网证用于非明文登记和核验真实身份 |

## 安全要求与实施

### 保证自愿使用和同等服务

**法规要求｜第4、6—7条。** 用户自愿申领和使用网号网证；平台接入后，应保留其他合法实名方式并保障同等服务。

**落实与验收。** 不以产品设计强迫用户申领网号网证；未使用公共服务的用户不能被降级。

**验收证据。** 使用两种实名路径完整走一遍核心功能，比较功能、价格、时延和权益。

### 身份信息最小化

**法规要求｜第7—9条。** 用户通过网号网证完成验证后，平台原则上不得再次索取明文身份信息；无需留存证件信息时只获取核验结果。

**落实与验收。** 身份核验接口默认返回“结果”而不是证件原文；确需明文信息必须单独判断依据和授权。

**验收证据。** 抓取实名接口返回字段，验证平台是否以“风控便利”为由额外保存身份证明文。

### 未成年人、数据境内和事件保护

**法规要求｜第4、10、12—13条。** 未成年人申领有监护要求；公共服务平台重要数据和个人信息境内存储，事件及时处置报告；密码应用符合国家要求。

**验收证据。** 验证未成年人路径、境外访问、日志、事件报告和密码实现是否符合对应专项法规。
