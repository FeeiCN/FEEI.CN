# 小型个人信息处理者个人信息保护简化措施规定

## 法规概览

| 项目 | 内容 |
| --- | --- |
| 发布 | 国家网信办、公安部，2026年正式公布 |
| 适用对象 | 当前处理不满10万人个人信息的个人信息处理者；已删除个人信息不计入人数 |
| 核心定位 | 在不降低个人信息安全底线的前提下简化部分履责方式 |

## 安全要求与实施

### 动态判断是否仍属于小型处理者

**落实与验收。** 从真实数据资产持续统计当前涉及自然人数，达到10万人前预警；规模、敏感信息和业务模式变化时重新判断。

**验收证据。** 从生产数据复算人数，而不是使用注册用户数或历史估算值。

### 简化不等于免除基本义务

**落实与验收。** 使用简化处理规则、告知和同意方式时，仍应满足最小必要、敏感个人信息单独同意、权利响应、删除和安全保护要求。

**验收证据。** 随机抽取一个简化告知场景，确认是否满足规定条件而非单纯因为企业规模小。

### 正确使用平台代履责机制

**落实与验收。** 仅通过网络平台处理且不向平台外提供等满足规定条件时，可利用平台统一规则、审计和影响评估；超出平台规则范围时恢复自身义务。

**验收证据。** 从真实接口和第三方SDK反查是否存在平台外处理，一旦存在就不能错误套用平台简化条件。

### 建立低成本但真实的审计和影响评估

**落实与验收。** 使用规定附件自查表和评估表开展审计/PIA；合规审计原则上至少每5年一次，其他法规有更严格要求的从其规定。

**验收证据。** 验证审计结论是否来自真实处理活动，认证有效期内免审等条件是否真实满足。
