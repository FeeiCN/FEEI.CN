# 持续拿到结果

**蚂蚁期间我观察到一种典型现象：年初定的目标很清晰，年中复盘时发现完成度明显偏低，但团队每个人都觉得自己很忙。** 调研后才发现：每个人的"忙"是不同方向的忙，加起来不形成合力。**目标清楚只是起点，中间需要一套机制把目标持续转化为行动。**

跟踪真实管理者的工作节奏可以发现，他们大部分时间花在跟进、协调、纠偏上，真正用于重大决策的时间反而有限。**拿到结果靠一连串动作的复利。** 这篇文章说的是这串动作具体是什么。

## 用小胜维持复利

**持续拿到结果的最小单位，是每天一个可控的小胜。** 外界看到一本书、一家公司、一个成熟系统、一个稳定习惯时，很容易把成品想象得很精彩，于是误以为创造它的过程同样精彩。真实过程通常朴素得多：坐下来写一段不够好的初稿，把一个客户问题追到底，把一个流程漏洞补上，把一个反复拖延的动作固定到日程里。它看起来不耀眼，却能被重复、被检查、被改进。

**小胜要避免随机多做一点事，要让事情在正确方向上往前移动一小步。** 如果一天结束时只是多回了几条消息、多开了几场会、多处理了几个临时需求，这些动作未必会沉淀成结果。有效的小胜要有明确对象：今天推进了哪个关键任务，修正了哪个判断，补齐了哪个缺口，减少了哪个未来会反复出现的摩擦。它可以很小，但必须能进入下一轮复盘，成为后续动作的材料。

**小胜要经过审视、拆解和迭代，才会进入复利。** 写作里每天写出粗糙初稿只是第一步，还要回头删改、重组、补例子、调结构；业务里今天发现一个转化漏洞，也要继续追问它从哪里来、是否可复制、谁来负责、怎样避免再次发生；个人成长里今天读到一个判断，也要在真实场景里验证，不能停留在收藏和标记。持续结果来自这些小动作彼此接住：前一天留下素材，第二天做出修正，下一次遇到类似问题时更快识别。

**每天的小胜会同时塑造作品、系统和身份。** 作品来自一页页不完美的稿子，系统来自一次次把问题流程化，身份来自没人看见时仍然做对的小事。一个人长期选择什么、遵守什么规则、如何对待细节、怎样处理看似不起眼的漏洞，最后会变成别人眼中的"能力"和自己心里的"我就是这样做事的人"。真正能控制的部分，往往藏在这些没有观众的日常动作里。

**不要等一个戏剧化的重启时刻。** 真正容易开始的方式，是把今天能控制的那一小步做掉：把一个模糊任务拆成下一步，把一个会议结论写成 action，把一个低质量产出改到能交付，把一个拖累效率的流程改顺。最早的小胜通常最费劲，因为它还没有惯性，也还没有外界反馈；一旦根扎下去，后续动作会更容易接上，结果也会开始互相支撑。

## 把每件事做到最好

**只有把每件事做到自己认为的最好、团队中最好、公司中最好、行业内最好，才更有可能取得引入注目的成就。** 每件事是指无论大事小事，可以选择不做，但既然做了就要都符合最好的标准。

**学习你对应层级最优秀的人甚至下个层级的人。** 我们总是过度看重那些自己崇拜的偶像，总是把他们的话当成至理名言。但我们最应该学习的是那些和自己差不多年龄，能力却比自己优秀的人——这些人的做事、思考对我们的帮助会更直接。

**每件事都会在未来某个时候产生结果。** 每件事不一定都能立刻显现结果，但都是在未来人生打下基础，播下种子，未来就会收获到对应果实。

## 做好时间管理

**规划好你的日程。当事情复杂程度超过了个人能力时，用清单管理关键节点。**

- **要事优先**
- **以终为始**
- **守时**

**时间分为日程时间和创作者时间。** 时间拆得越细，越容易被会议、消息和临时需求切碎；面对不同的任务，需要区分考虑。**一段完整深度工作，往往比长时间低效工作产出更高、疲惫更少、长期收益更大。** 时间管理的核心，是管理单位时间内的深度，避免堆砌总时长。

## 怎么跟进事情

**意义**：共同对焦目标和价值，最大限度激发员工的参与感和内在动力，及早发现问题解决问题。

**跟进关键任务**：问进展、问风险、给建议、做辅导。

**多给空间多观察**：多放手给员工完成规划的时间和空间，少干预。**在用的过程中养人，在养的过程中用人。**

**多沟通**：

- 1v1 沟通：加强与同学的信任和了解
- 团队沟通：促进团队彼此的了解和共识
- 形式要接地气：不假大空、不矫揉造作、没有架子、自然就好、直接、直言有讳
- 内容要讲人话：简单、言简意赅、清楚明确
- 心态要视人为人：开放、待人要真诚、真情实感、有原则、捍卫自己的观点
- 向上沟通：有胆量

**跟进时的常见误区**：

- 到了 deadline 才检查，过程中不跟进
- 不讲 why，只给方法
- 只关注 how much，忽略 how
- 把追结果当做追过程
- 不够持续，随性工作
- 过渡的干预和打断会让员工束手束脚
- 不影响项目推进的情况下，允许员工犯小错

## 怎么复盘

**用好的复盘挖根源、快复制，根据状况及时调整策略、任务、分工，做好上传下递，开启新一轮策略打法沟通共识。**

**何时需要复盘**：

- 业务进展理想、数据漂亮时要复盘——总结经验和方法，复制到更多的团队和业务，总结规律，形成流程，转化为团队的财富
- 业务进展不理想，与预期有偏差要复盘——追其根源，快速调优和改善，避免同样的错误再发生
- 小事及时复盘——行动结束或问题发生，及时复盘，制定改进方案并落实
- 大事阶段性复盘——大的项目要阶段性复盘（每周、每两周）对焦目标，策略及时调整
- 事后全面复盘——大项目或大战役结束后要进行总结复盘，找到规律，汲取教训

**复盘原则**：

- 希望达成什么样的目的，比如让相关方重视相关问题
- 要确定有什么结论和 action，action 要明确到人和时间
- 涉及的相关同学要拉齐，要明确大家能到场
- 拉上大领导对事件进行表态，让大家意识和重视程度更高
- 可以事前分别跟各方对齐各类事情，避免会上争论，提高开会效率
- 讲的内容要让参会的各方都能听懂

## 平衡工作与生活

**让自己始终处在舒适区边缘**——太舒服没成长，太紧绷会崩溃。

**工作时注意留点时间休息**——比如下午三四点，避免下班后觉得没有全在工作没有个人时间，导致熬夜。

## 持续拿到结果的关键

**"持续拿到结果"真正重要的判断是：持续努力要和持续选择绑在一起。** 大多数人以为结果来自"每天多做一点"，但真正持续拿到结果的人，会让自己每天少做错一点。

**两个看似都在"努力"的人，几年后差距巨大，通常来自选择质量的差异。** 谁更会选该放弃的事、该做对的事、该优化的环节，谁就能把同样的努力放大。努力是基础，选择是放大器。

**几个具体的：**

- **"忙"本身没有问题，"忙但没结果"才有问题。** 一个真正持续拿到结果的人，表面上可能看起来"不那么忙"，因为他把精力放在做对的事上，减少低价值动作。**忙但不产生结果，是常见的"努力幻觉"。**
- **"跟上进度"和"持续拿到结果"是矛盾的。** 跟上进度是被节奏推着走；持续拿到结果是自己定节奏。**真正持续拿到结果的人，会主动调整进度：该快就快、该慢就慢，避免一直跟着别人定的节奏走。**
- **"沟通"是结果的隐性杀手。** 大多数执行问题来自信息不一致：重复劳动、方向错误、关键风险没人同步。把时间提前花在对齐上，往往比事后返工更有产出。
- **"复盘"要产出可复用的判断。** 大多数复盘只是回顾发生了什么，没有抽象成"下次如何更快识别"。真正厉害的复盘，会让同类问题下次出现时更早暴露、更快解决。

**持续拿到结果要建立可复制的系统。** 一个人减少低价值消耗后仍然产出更高，通常来自更成熟的系统。**系统的最大价值是：让你不需要每次都从零开始。**
