杂项爱好记录那些不属于阅读、影视、旅行、音乐的兴趣和生活方式判断。它们看起来零散，但共同指向同一件事：让生活保留审美、感受力、好奇心和真实偏好。

- **[房屋设计与装修](/home-design)**：围绕居住空间、装修决策和生活方式做长期判断。
- **[诗词歌赋](/poetry)**：古典文字带来的表达、格局和审美训练。
- **[审美与品味](/taste)**：判断什么是好、为什么好，以及如何训练自己的品味。
- **[物品与极简](/stuff)**：处理物品、空间、消费和心智能量之间的关系。
- **[算命背后的科学](/fortune-telling-science)**：从兴趣出发，理解概率、心理和人对确定性的需求。
