# 事业有成

对我来说，事业有成意味着通过长期投入，形成解决重要问题的能力，创造真实价值，并保有选择下一阶段的自由。薪资、职级和创业规模可以反映部分结果，但不能单独定义一段职业是否值得。

这套内容来自我在安全领域的工作与管理经历，主要面向技术型知识工作者。公司规模、岗位序列和家庭条件会改变方法的适用性；涉及大厂的经验，使用前需要对照自己的组织。

## 按当前处境开始

- **正在选工作或考虑转型**：从[职业与事业](/career)开始，再按需要读[职业转型与退出](/career-transition)、[薪酬谈判与机会比较](/compensation-negotiation)或[应对被裁员](/handling-layoffs)。
- **工作多年，专业判断没有明显进步**：从[成为专家](/expert)开始，用[专业判断的训练方法](/professional-practice)把任务、反馈与知识沉淀连起来。
- **做了很多事，却没有形成重要结果**：从[拿到结果](/result)开始，先[识别真正值得解决的问题](/problem-selection)，再检查目标、交付与评价；业务视角不足时读[技术工作者如何理解业务](/business-understanding)。
- **有方案，但推动不起来**：从[影响协作](/influence)开始，理解相关方的约束；遇到利益冲突或职责调整时读[冲突、边界与组织变化](/conflict-and-organizational-change)。
- **开始对一群人的产出负责**：从[管理团队](/manage)开始，设计运行机制，再用[培养他人与授权](/coaching-and-delegation)帮助成员逐步独立。

## 专家、管理与创业可以分支发展

专业深度和协作能力可以支撑长期专家路线。管理需要承担人员、资源和组织运行责任，不能仅靠技术优秀推断是否适合。创业则增加了用户、收入、现金流和经营风险，也无需以做过管理者为前提。

[领导力](/leadership)讨论如何在不确定和分歧中组织行动，适用于项目负责人、专家和管理者。[创建事业](/boss)讨论如何用有限投入验证创业机会。[思维](/thinking)提供按问题查阅的判断工具，不要求从头读完。
