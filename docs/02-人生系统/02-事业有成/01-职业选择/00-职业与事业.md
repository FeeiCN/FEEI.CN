# 职业与事业

选工作时，薪资和头衔容易比较，几年后会形成什么能力却很难估计。我的判断是：一份值得投入的工作，需要同时有真实需求、适合自己的问题、能够学习的环境，以及可承受的代价。

我从漏洞研究走到企业安全建设，再进入金融与支付领域，路径中既有能力积累，也有业务窗口和他人支持。个人努力能提高抓住机会的可能，不能控制机会是否出现。职业规划要同时处理成长与风险。

## 先判断这份工作在解决谁的问题

行业增长可以增加机会，但行业标签不能替代岗位判断。进入热门行业，也可能长期做重复工作；成熟行业里，也可能存在重要且稀缺的问题。

选择前尽量问到具体对象：服务哪些用户，问题不解决有什么损失，团队为什么现在需要这个岗位，资源是否已经落实。把“前景很好”转换成可核对的业务需求，才知道自己的工作是否有长期支点。

## 优势要通过真实任务验证

兴趣能支持持续投入，已有能力能降低起步成本，市场需求决定别人是否需要这份产出。三者有交集时，职业更容易持续；缺少任何一项，都需要说明准备怎样补齐。

“别人觉得难、我做起来相对顺手”可以作为优势线索，但仍需观察成果是否可靠、别人是否愿意采用、自己是否愿意承担这项工作的重复部分。一次轻松完成的任务，不能直接证明天赋或长期竞争力。

在重大转型前，用兼职项目、公开作品、内部轮岗或小规模合作验证。记录投入、产出、反馈与疲惫感，避免仅凭对新身份的向往做选择。

## 团队决定你能得到怎样的反馈

未来同事、主管和合作方会改变自己的工作标准。比平台名气更值得追问的是：谁能指出我的错误，项目结束后是否复盘，优秀的人为什么留下，坏消息能否真实汇报。

[一位 NVIDIA 工程师的十年职业复盘](https://maxlv.net/blog/suggestions/)可以作为行业、长期积累与队友质量的讨论材料。成功后的回顾容易受幸存者偏差影响；评估自己的机会，应写下当时可见的依据，不能用后来股价或职级倒推当初必然正确。

专业成长可以从[成为专家](/expert)继续；已经能独立交付、却难以推动采用的问题，转到[影响协作](/influence)。专家路线和管理路线可以并行探索，无需把转管理视为唯一上升方式。

## 求职要管理节奏和信息

求职是一项项目：先明确岗位标准，再准备代表作和经历证据，了解团队招聘窗口，安排面试节奏，最后比较实际条件。

- **准备证据**：选几项真实项目，讲清问题、约束、个人贡献、结果和失败，不把团队全部成果归给自己。
- **询问团队状态**：职责、汇报关系、招聘原因、预算和考核要求，比职位名称更能说明实际工作。
- **安排面试顺序**：保留练习机会，也给重要流程留出体力与准备时间。
- **核对 offer**：确认薪酬组成、职责、工作地点、试用期、竞业条款和签署期限，重要承诺尽量形成书面记录。

安全岗位的专项准备见[网络安全面试指南](/sig)。面试失败可能来自能力差距，也可能来自岗位关闭或匹配变化；复盘要区分能改进的部分与外部条件。

进入条件协商时，读[薪酬谈判与机会比较](/compensation-negotiation)，将确定收入、附条件奖励和非金钱取舍分开比较。

## 用选择权管理转型风险

离开旧岗位前，估计家庭固定支出、收入中断期、新方向最小验证成本，以及最坏结果能否承受。准备现金缓冲、降低不可逆承诺，通常能增加试错空间。提前还贷、投资或暂停工作是否合适，需要按自己的流动性与责任判断。

转型实验最好预先写清四件事：希望验证的假设、观察到什么算有进展、什么时候停止、停止后回到哪里。若新方向长期没有证据，继续投入需要新的理由，不能只依赖已付出的时间。

主动转岗、跨行业或离职的验证与交接见[职业转型与退出](/career-transition)，失业与劳动关系事项见[应对被裁员](/handling-layoffs)。[蚂蚁五年](/5-years-ant)记录了我在收入、成长和自由之间的变化，适合作为一个个人案例对照。
