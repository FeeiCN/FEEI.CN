# 沟通与表达

**蚂蚁期间我观察到一个现象：同样一份方案，技术 P8 讲出来业务方听不进去，换一个 P9（甚至 P7 但表达能力强的）讲就听得进去。** 差异不在内容本身，在表达的人。**沟通是让别人愿意听；表达是让别人愿意信。** 两者是不同能力，但经常被混为一谈。

## 沟通的几个底层原则

### 行动起来，不管结果怎么样

**沟通的最大问题，是总想当然地认为已经沟通了。** 如果面对关键问题去逃避，后续工作和生活都会一团糟。**不确定性中也有确定性。** 主动沟通不是保证结果的，但回避沟通几乎必然让结果变差。

### 百闻不如一见

**面对面沟通的体验，让人能感受到你的气质、眼神中的坚定、语言中的善意。** 那种耳目一新和如沐春风的感觉，是任何工具无法替代的。**重要的沟通，争取面对面。** 视频次之，电话第三，文字最后。

### 坦诚友善

沟通时，我们总是会下意识以祖先面对危险时最原始的应对方式——暴力对抗或转身而逃。**更有效的应对，是采取机智的说服和友善的关注来解决问题。** 成功对话的关键在于自由坦诚的交流——双方愿意表达自己的看法、分享自己的感受、说出自己的猜测，即使表达的是充满争议或不受欢迎的，他们仍然愿意积极分享。**感性的东西会让我们感受到真情流露，感同身受，会有更好的结果。**

### 沟通要永远关注自己真正的目的

**不要把全部希望寄托在他人身上。** 沟通的目的不是"让对方听我"，是"达成我真正想达成的事"。如果把对方听我当成目的，沟通就变成了表演。

### 先确认角色，再开口说话

**身份和角色决定了什么话是对的、什么是该说的、什么是不该说的。** 同一件事，员工说和老板说、专家说和外行说，含义和效果完全不同。**开口前先问：我现在是以什么身份在说这句话？**

### 互惠原理

**先给予，会让对方产生回报的义务感。** 先提出大请求后撤为小请求（拒绝-后撤），对方会因为"我让步了一次"而更容易答应后续的请求。

### 褒奖好行为，比惩罚坏行为，效果好十倍

**特别是在培养习惯、教育和管理中——强化你想要的行为，比对抗你不想要的行为高效得多。**

## 倾听的几个细节

**先理解别人，再被人理解，从倾听开始。**

几个倾听的实操：

- **事实、观点、立场、信仰**——区分对方说的是哪一层
- 思考、感受他人内心所想，并以此为逻辑起点展开自己的推论和行动
- 拥有其相关经历的，想象当时经历时是什么感受
- 没有经历过的可以临时体验下
- 无法体验的就找有经验的人帮助
- 读史书应该把自己想象成书中人，会怎么做——现实中遇到事情时，历史的人会怎么做
- 如果我是他，我会怎么样
- 像个外人一样观察自己
- 观察身边某个人喜欢什么
- 全局分析、客观事实、感性直觉、乐观思考、保守行事、创新思维

## 表达的几个核心动作

**讲那些你已经理解很透彻深刻的观点。** 讲不透彻的观点，会被听众的本能识破——讲的人越自信，听的人越怀疑。

**讲小故事。** 人们天生喜欢听故事，故事能表达很多内容，自己经历的故事也会更细节生动。**故事的逻辑可以按照提出问题、再给出解决方法——也就是痛点+焦虑+解药。**

**结论先行，论据支撑，详细证据。** 这是商业表达的金科玉律。**先让对方知道你讲的是什么，再让对方知道为什么相信，最后让对方看到证据。**

**跨界比喻。** 痛点 + 跨界比喻 + 独特解决方案——一个好的跨界比喻能让对方瞬间理解一个新概念。

**调动现场气氛的几个技巧**：

- 问一个大家关心的问题
- **融入一个笑话**。比如有次演讲，在时间很赶的情况下，前面几个演讲者讲得非常好，我上台就用非常疑问的语气说："大家这两天都是上车睡觉，下车撒尿，每天都那么晚，前面演讲者是怎么有时间准备得那么好的？"
- 保持真诚——不真诚的笑话比不笑还糟

**更流畅自信的表达**：

- 避免使用口头语，比如这个、那个、嗯、额、是吧、然后等
- 适度放慢语速——紧张的人会不自觉加速
- 重要的内容用停顿强调

**有趣 + 知识 + 共鸣是衡量表达力的三个最重要因素。** 缺任何一个，听众都会走神。

## 几个能立刻用上的说服动作

**给请求附加理由，哪怕理由很简单。** 大脑接收到理由后，会默认视之为既定事实，从而倾向于接受请求。**有理由的请求比无理由的请求，接受率显著更高。**

**具有说服力的人，善于用故事让人看到原本看不到的价值。** 数据和逻辑说服理性，故事唤起感受。**想让别人真正接受一个观点，给他讲一个能让他"身临其境"的故事，比列举论据更有效。**

**人们会忘记你所说，忘记你所做，但会铭记你给他们的感觉。** 每次互动留下的情感印象，比内容本身更持久。**平时积累的信任和好感，是危机时刻最可靠的缓冲。**

**说服力来自三个来源：知识、权威、威权。** 知识优势（你懂他不懂）、专家光环（公认的专业地位）、权力威信（行政权力或德高望重）。**没有权力时，专注建立知识优势和专业权威是最可持续的路径。**

[Dan Koe 对人性与说服的拆解](https://x.com/thedankoe/status/2073418764058825045)把威胁、身份、归属、未来想象和低门槛第一步视为可练习的心理杠杆。理解这些机制有助于解释人为什么行动，也必须设置伦理边界：不隐瞒重要代价，不制造虚假稀缺和恐惧，不利用身份羞辱绕过理性选择。可信的说服让真实问题更清楚、让第一步更容易验证和撤销；一项方案如果只有在对方不知道关键信息时才会被接受，那是操纵，不是沟通。

## 一个判断

**沟通表达真正重要的判断是：表达力的天花板不在"怎么说"，在"听谁说"。** 同一个人讲的话，在不同听众那里得到的反馈天差地别——因为"信任"是表达的前置条件，没有信任，再好的表达也没用。

**几个值得注意的具体判断：**

- **"会说话"不是表达力——"让人愿意听你说话"才是。** 大多数人以为表达力是"能说会道"——但真正的表达力是"听你说话的人觉得你值得听"。**这种"值得听"不是靠话术，是靠之前的判断、之前的成果、之前的关系。**
- **"对事不对人"是个谎言。** 沟通永远是对人的——你说的话、你提问的方式、你表达的态度——都在传递"你把对方当什么人"。**真正有效的沟通是"把人当目的"——让对方感到被理解、被尊重、被认真对待。**
- **"双向沟通"不是"你说我听"——是"我们一起重新看问题"。** 真正有价值的沟通是双方都改变了对问题的看法——而不是谁说服了谁。**如果沟通后双方看法都没变——这种沟通是浪费。**
- **"不沟通"往往比"沟通"更好。** 不是所有事都需要沟通——不重要的、不需要对方同意的、对方不会真正在乎的——保持沉默比强行沟通更尊重对方的时间。**真正的沟通高手知道什么时候不沟通。**

**表达力的最终判断：不是"我能说清楚"，是"我能让你愿意做"。** 表达的目的是行动，不是传递信息。**如果你的表达没有让对方有任何行动——再精彩也是失败的。** 真正改变人的表达不是"有道理"——是"有道理 + 让对方觉得"我要做"。
