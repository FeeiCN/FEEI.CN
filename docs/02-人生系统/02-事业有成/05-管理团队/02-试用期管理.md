# 试用期管理

面试形成初步判断，试用期用真实工作验证，同时帮助新人理解业务与协作方式。目标是尽早确认匹配与改进方向，既不默认所有新人都能留下，也不以主动淘汰为成绩。

管理者需要把岗位期待、资源和反馈讲清楚。新人表现不足时，还要检查授权、培训、目标和时间是否合理，不能仅靠一场答辩作决定。

## 入职前说明条件，入职后落实支持

录用条件和岗位要求应提前明确并依法告知，不能在结束时临时追加标准。确定带教人、业务材料、系统权限和必要培训，让新人知道找谁获取信息与帮助。

了解新人经验与兴趣，尊重隐私，不强求披露家庭和健康等与岗位无关的信息。原有经验可以提供价值，也需要按新环境核对适用性。

## 用少量真实任务验证岗位能力

任务要与岗位相关，具有清晰范围、成果标准和期限。培训、权限开通与环境学习所占时间应进入安排，不把全部试用期当作成熟员工的正常产能。

可以从边界清楚的小任务开始，再逐步观察独立交付与协作。多项并行任务若无法辨认个人贡献，或主要是无关打杂，就难验证人岗匹配。

## 定期反馈差距与所需帮助

按任务风险安排阶段沟通，记录成果、困难、具体反馈和支持。让新人知道当前判断与改进重点，不能到最后突然告知一直不合格。

差距出现时，区分知识、方法、资源和目标理解。安排相应帮助与观察点，并核对目标调整是否公平。汇报频率按需要设置，不把日报本身当成能力指标。

## 阶段总结补充证据，不取代日常观察

总结可以围绕目标、判断、行动、结果、困难和下一步。评审者应了解岗位与实际任务，用相同标准核对材料和协作反馈。

表达技巧与实际工作能力分别评价。一次紧张、某个问题答不上来或没有宏大规划，不足以替代全部工作证据。必要时核对来源，避免单个主管的印象决定全部结论。

## 去留判断必须符合劳动法律边界

试用期并非可以任意解除劳动合同。中国大陆劳动关系下，[《劳动合同法》原公布文本](https://www.gov.cn/flfg/2007-06/29/content_669394.htm)第19至21条及第39、40条等涉及期限、工资和解除条件；处理实际事项时需核对现行修订、相关司法解释与个案事实。

“不符合录用条件”需要相应依据，不能直接等同于主管不满意。程序、证据和说明义务应由 HR 与劳动法律专业人员核对。公司内部答辩通过或未通过，不自动决定解除是否合法。

## 验证之后安排后续发展

匹配时明确接下来的职责、培养目标与反馈节奏；不匹配时及时、具体、尊重地沟通，依法处理，避免持续悬而不决。

新人也在判断组织是否兑现承诺。真实信息、可获得支持与明确规则，会让双方更早作出有依据的选择。常规培养与授权见[知人善用](/managing-people)。
