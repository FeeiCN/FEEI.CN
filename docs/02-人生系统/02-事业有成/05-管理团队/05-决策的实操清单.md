# 决策的实操清单

用于项目、资源和流程等工作决策，可与[善决策](/decision-making)的机制分析配合。以下是检查问题，不是已经证明适用于所有场景的标准。涉及法律、投资、安全和重大人事事项时，需补充专业评审与正式程序。

## 决策前核对范围

- 要改变什么，谁受影响，维持现状会怎样？
- 谁有权决定，谁执行，谁承担后果？
- 是可逆试验，还是会产生不可逆承诺？
- 期限由真实窗口决定，还是来自人为催促？
- 失败是否可能超过可承受范围？若会，先缩小暴露或升级评审。

## 把信息与推断分开

- 关键事实来自哪里，时间与版本是否匹配？
- 哪些是已经验证的事实，哪些是估计与假设？
- 至少有什么证据可能推翻当前建议？
- 是否需要一线信息、独立数据或相关专家参与？
- 信息不足时，能否通过低成本试验补充，而非直接给出确定答案？

管理者需要足够专业理解来追问与判断，也需要借助团队专家。要求自己比所有下属更懂全部细节，会成为授权与发展瓶颈。

## 比较方案与机会成本

- 是否包含不做、延后、缩小范围和替代方案？
- 每种方案的收益、成本、依赖与最坏后果是什么？
- 概率估计依据是什么，哪些变化会改变排序？
- 哪个选择会挤掉其他重要工作？
- 可逆性、流动性、合规与长期责任是否已经纳入？

两个选项难以抉择，也可能是缺少信息或目标冲突，不能由此认定任选都不会错。只有确认差异小且失败代价可承受时，才适合简化选择。

## 组织讨论与授权

- 重要判断是否先独立收集，避免主管先定调？
- 执行方与风险承担者是否有表达机会？
- 反对意见是否得到事实回应？
- 最终决策是否明确，分歧是否留有记录？
- 一线可自行决定的范围、资源与升级条件是否清楚？

匿名意见有时有帮助，但不是所有讨论的必要条件。按风险与表达环境选择方式，不以讨论次数替代决定。

## 决定后绑定检查点

- 写下关键假设、完成标准、负责人、期限和依赖。
- 约定观察什么证据，何时复查，什么情况下暂停或停止。
- 重大变更重新确认授权，不让范围默默扩大。
- 复盘区分判断、执行和外部变化，记录下一次如何调整。

## 决策记录模板

```text
问题与日期：
决策权限、执行者与受影响者：
已核实事实、来源与未知项：
备选方案与不做的后果：
关键假设、风险边界与选择理由：
负责人、资源、期限与依赖：
检验点、成功信号与停止条件：
复查结果和下一步修正：
```

历史推演可以帮助练习，但需只使用当时可得的信息，明确无法验证的反事实。训练优先选择可记录、能获得反馈的真实小决策，而非用已知结局证明自己的判断力。
