# 团队文化

墙上写什么与实际奖励什么可能不同。团队文化要在具体决定里观察：谁能提出坏消息，哪些行为得到认可，冲突如何处理，出了问题谁承担责任。

我更希望团队能坦诚交流、获得自主空间，也清楚工作义务。友善与高标准可以共存；表达不舒服的问题，不应意味着受到羞辱或报复。

## 约定要能对应真实行为

“开放”可以落实为允许提问、回应异议与解释决策；“负责”可以落实为及时同步风险、履行承诺和正确归因。使用能观察的行为描述，避免抽象词变成主管随意判断的工具。

称呼、工位和活动可以传递信号，但更重要的是权限、评价和日常待遇。叫花名不代表没有权力差异，管理者仍需主动降低表达压力。

## 开放信息也要保护隐私与秘密

公开目标、进展、依赖和决策理由，减少不必要的信息差。团队正式材料按责任与权限共享，个人信息、客户数据、薪酬等不能默认对全员开放。

讨论渠道应允许合理批评，并保护提出问题的人。内容涉及泄密、隐私或违法时，可以依规则处理，保留说明与申诉渠道；不能用“任何帖子都不删”替代必要治理。

## 自主需要清晰规则与资源

任务、工作安排、预算与假期按公司制度、法律和职责约定。管理者能授予的空间要说明范围，不能一方面说不看时间，另一方面要求猜测隐藏的出勤标准。

有意愿尝试新方向的人，需要合适任务、资源和反馈。没有进展时核对条件与方法，不以自主为名放任，也不以保护为名长期回避明确反馈。

## 异议与错误要有公平处理方式

坏消息出现时，先核对事实与影响，及时止损，再分析责任。若每次报告问题都带来惩罚，团队会更倾向隐藏。心理安全与免除责任不同：允许说明和纠错，也需要处理明确违规。

可参考[Google re:Work 对团队效能的研究介绍](https://rework.withgoogle.com/intl/en/guides/understanding-team-effectiveness)。它提供研究与实践背景，不能证明某一种文化公约在所有团队都有效。

## 温度不等于无条件奉献

庆祝、团建与关怀可以帮助认识彼此，应尊重参与意愿与私人时间。雇佣关系不能用家人或兄弟叙事替代：工作义务、休息权利、奖励与离职条件仍需明确。

管理者以身作则，包含遵守约定、承认错误、保护休息和公平评价，不仅是自己加班更多。强制排名可能产生自保与竞争行为，需要检查是否仍服务于真实贡献。

## 用多种信号检查文化

观察成果、负荷、反馈质量、人才成长与离职原因。问卷、投诉和离职率都有测量限制，分数高或投诉少不等于没有问题，奖励比例也不单独证明健康。

定期问成员：哪些约定正在兑现，哪些话不能说，哪个决定与公开原则冲突。把答案转成具体改进，并说明处理结果。长期一致的行动，比增加文化口号更有说服力。
