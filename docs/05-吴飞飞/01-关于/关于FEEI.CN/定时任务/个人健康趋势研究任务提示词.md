数据读取与校验：
1. 先读取 FeeiCN/FEEI.CN 的 AGENTS.md 和必要的现有解析规范，特别是 docs/05-吴飞飞/01-关于/关于FEEI.CN/SKILL/健康数据存储规范.md。将用户给出的 https://feei.cn/data/health/ 作为网站访问基址，不将它误当作必须从 Git 读取的仓库路径。优先访问已知日期的具体 JSON，而非依赖目录列表；目录本身不能列出文件不等于日期数据不可访问。可读取同一基址下的 sync-status.json、sources.json 及日期索引帮助定位，但这些索引和缓存不是测量结果。以实际 HTTP 响应、JSON version 和当前解析代码确认线上格式，文档中的合成示例、暂存验证状态不能证明线上已迁移或替代真实测量。
2. 若线上为 v5，日期入口为 YYYY/MM/DD.json，例如 https://feei.cn/data/health/2026/11/01.json；以日级索引及其声明的 revision、files 为事实读取链。先用轻量日索引获取需要的体重、活动、睡眠、心率与 HRV 汇总，确需细节时再按 files 中实际声明的相对路径读取 gzip 分片。仅读取该日索引声明的 revision，不猜测哈希目录、不扫描分片目录。处理 gzip 时遵循 Content-Encoding 与实际响应，避免重复解压；记录完整性与哈希校验的实际结果，未执行不得声称校验通过。列式指标按实际 columns 与 rows 映射，并核对 metric.name、units 和 sources.json 中的 sourceId；不能硬套旧版 date/qty 对象数组。日期偏移按格式规定结合 Asia/Shanghai 还原。月文件 YYYY/MM.json 若为生成的趋势缓存，只用于定位、交叉核对与加速，不冒充唯一原始事实源；缓存和日级事实不一致时，以可核验日级事实为准并说明冲突。
3. 若实际线上仍有旧版完整数据，依据真实响应解析 exportedAt、dateRange、data.healthMetrics.metrics，以及 name、date、qty、units 等字段；不因新版规范存在就否认旧格式。重点指标为 weight_body_mass、apple_exercise_time、step_count、sleep_analysis、resting_heart_rate、heart_rate_variability，或新版日索引中经实际解析代码确认的对应字段。必要时可读取 workouts、medications、stateOfMind，但仅在用户目标相关且数据真实完整时引用。不将 lean_body_mass 或 body_mass_index 当作体重。体重统一以市斤呈现，原始 kg 按 1kg=2斤转换，不改原文件。
4. 按需要读取当前及此前三个月，日期范围依每次执行时刻动态计算。核查实际测量时间、导出时间、最新记录日期、同步滞后、缺测、重复、单位变化与设备来源差异；区分零与缺失、采集与导出日期、完整日与当日部分数据。跨来源不得重复累加，workouts 时长不与 apple_exercise_time 叠加。涉及睡眠跨午夜归属，按实际解析规范使用一致口径。
5. 访问失败时区分 HTTP 状态、DNS/网络错误、抓取工具限制、认证要求和数据解析问题，不能把工具的 Cache miss 或访问失败直接写成站点停机或数据丢失。可在同一授权基址下对已知具体索引做有限重试，不绕过登录、读取凭证或扩大抓取范围。仍失败则明确说明本次未读取到真实数据、失败层级及能从此前报告核实的上次数据截止日，不补数、不生成趋势；相同障碍无变化不重复长篇通知，不因一次或临时读取失败自行停用任务。

每次研究：
1. 使用 Asia/Shanghai 计算最近一个完整自然周、过去30天及必要时过去90天的有效记录数量与趋势，排除尚未结束的当天。体重以记录日周均或中位数及长期变化为主，先按一致规则合并同日测量，避免多次称重的日期被额外加权；不以一次波动下结论。运动统计有有效记录完整日中达到30分钟的天数，同时给出有效记录日数；分析步数、睡眠时长/规律以及可用的心率/恢复指标。比较窗口与数据覆盖不同必须披露，不将不完整周均称为完整周均。
2. 对照上次同口径报告和用户已有运动目标，按指标、时间窗口、变化方向去重，只突出有实质变化、持续趋势或数据质量异常的现象。不能从相关性推断病因，不做诊断、处方或自动调整药物/治疗，不推荐极端节食。
3. 每期最多给出一个低风险、可执行、可衡量的行为调整或小实验，说明持续周期、成功标准及下期复核方式。没有明确行为证据不宣称完成或失败。出现持续异常或危险症状时提示适当就医，不用可穿戴数据代替临床判断。
4. 需要外部医学或运动建议依据时，检索可靠临床指南、系统综述或权威公共卫生资料并注明适用范围；区分医学证据与个人观察，关键建议给出来源。
