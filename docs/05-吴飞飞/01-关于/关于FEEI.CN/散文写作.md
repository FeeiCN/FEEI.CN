适用于 `docs/04-experience/`（人生丰富）目录下的散文、游记类文档。

这一类文章遵循中国散文传统，**不适用** `我的写作原则` 中的金字塔结构和"先给核心结论"原则——散文以画面和叙事推进，不预设结论。

## 核心原则

观察胜于议论，留白胜于总结。写事不写理，写景更写人；先观察后思考，少结论多留白。

## 散文 vs 日志

散文最大的敌人是日志化——把游记写成"第 X 天 + 行程清单 + 工作备注"的混合体。要避免这些动作：

- **散文里回避工程语和工作日志黑话**："Claude Code"、"提交推送"、"Jira 单号"、"基于 issue 驱动的功能" 这种工程词汇会立刻把散文拉回日志，一律退回到散文语言——"把拖了几天没做完的事做完" 就够了。
- **品牌名要保留**：CU、Ediya、Airbnb、Cybertruck 这种是具体场景的锚点，删掉反而失真。区分原则：工程语（工作语言）回避，品牌地标（场景语言）保留。
- **散文不点明天数/顺序**：不要写"第一天/第二天/最后一天"。让时间顺序从场景切换里自然流露。"最后一站" 比 "旅行的最后一天" 干净。
- **行程清单不算散文**：列时间、列地点、列做了什么，本身就是日志体。散文要有场景、有观察、有动作，否则只是更长的 Markdown bullet。

## 段落结构

- **不一句一段**：把相关句子合并成段，让段落承担意义单元。
- **一个自然段一个场景**：段内围绕同一画面、同一时间切片或同一处细节展开；切换场景另起一段。
- **单场景值得多段**：同一个地点、同一段时间切片内，可以连续展开三四段，把不同尺度、不同人物、不同侧面都写进去。汉江那一节用五六个段落写同一片草地、同一段时间内不同人——这种写法让读者有在场感，比快速切换更像散文。
- **一段只围绕一个核心观察**：不要把多个观察并列堆在一段里（"挤 + 摩托车炸街 + 卫生间少 + 垃圾桶少" 四件事塞一段，会互相稀释）。挑一个核心观察（身体感受、空间感受、人物速写都可以），其他退为背景或单独立段。

## 叙事原则

- **少议论**：让事实、场景、对话自己说话，避免插入"由此可见""我们应该"这类判断。
- **不总结人生**：不写"这次经历让我明白了一个道理"这类升华。读者自己会感受到，作者不必点破。
- **不写"旅行让我明白了什么"**：这是游记中最常见的俗套。点到为止的领悟也不要展开成段落。
- **以真实素材推进**：用具体的地名、人名、时间、对话、价格、动作、感官细节推进叙事，不要用抽象论述替代素材。
- **写反应，不写判断**：不要写"机场的食物真贵"——这是判断。要写"付款的时候看见价格，还是忍不住多看了一眼"——这是反应。让读者自己得出结论。
- **场景里要有人**：每个场景至少有一个具体的"别人"——不是风景里可有可无的路人，而是有具体动作、具体反应的人。五芳斋那个年轻人、烤肉桌旁的下班族、飞机邻座、鞠躬的司机——他们各自有一个动作或一个反应。没人出现的场景就少了骨架。
- **微动作代替总结**：不要写"他看了一眼窗外"，要写"他睁开眼看看窗外，很快又睡过去"。具体到身体部位、动作、后续反应——"手搭在方向盘最上方""端着咖啡站了一会儿""端着餐盘走开了"。让读者看到画面，不是听到概括。
- **多尺度观察**：同一个地方从不同尺度去看——民宿：室内整齐 → 楼下巷子 → 窗外晾衣；烧烤店：桌挨桌 → 隔壁桌年轻人 → 烤盘的油 → 天花板排烟管。不要只写一个镜头，要上中下、里外、远近几层都看一遍。
- **动词链代替形容词**：不要写"匆匆忙忙的人"，要写"推着行李车快步往前赶"。动词本身带出速度、姿态、情绪，比形容词更具体。
- **地名锚定**：能用具体地名就不要用泛指——"纛岛汉江公园"比"汉江边"具体、"广藏市场，也叫紫阳市场"比"传统市场"具体、"梨花女子大学"比"一个大学"具体。地名是散文最稳的骨架。
- **观察对象的动作要写完整**：不要只给一个动作就切回叙述者——"指了指"补到"指了指 → 又朝那个方向挥了挥手"。完整的动作链 = 动作 + 后续反应。让对象在画面里多停半秒，再切回"我"。

## 私人经验的冒险感

有些生活方式类素材，真正有价值的部分，是它把一种活法写得有温度、有风险、有场面。处理这类素材时，不要把原文里夸张、冒犯、危险或明显带表演性质的价值判断照搬成站内原则；要拆出它背后的写法：作者如何让读者相信，某一种穿着、饮食、地理、关系、阅读、运动或夜晚，确实改变了一个人的状态。

- **从失控的具体时刻开场**：私人经验如果从"我最近有一些思考"开始，气会散。更稳的方式是从一个具体到身体的瞬间进入：窗开着、风吹进来、杯子还热、书摊在桌上、人在某个地方短暂失去时间感。读者先进入现场，再接受作者的状态。
- **让物件承担身份，不直接宣布身份**：亚麻衬衫、一本摊开的书、一杯特定的酒、冲浪板、机场便利店的咖啡、民宿窗边的拖鞋，这些物件可以把人放进某种生活里。不要直接写"我很自由""我很有品味""我过得很冒险"，让物件、使用方式和周围人的反应把身份慢慢显出来。
- **把环境当作情绪的证据**：很多情绪并不只来自性格，也来自空间。一个人烦躁、沉闷、暴烈、松弛或重新活过来，往往和他站在哪里、被什么声音包围、能不能看见远处有关。写这类变化时，不要急着给心理判断，先写他被困住的房间、潮湿的街、风从哪边来、身体哪里先松下来。
- **写强度，也写代价**：咖啡、酒、夜生活、冲动旅行、激烈关系都容易制造文本强度，但强度不能自动等于好。可以写它们带来的兴奋、清醒、靠近、荒唐和自由感，也要让读者看见边界：疲惫、失控、误判、伤害、第二天的沉默。这样文章会有重量，而不是变成生活方式广告。
- **挑衅要服务于筛选读者，不服务于羞辱别人**：有些文章靠冒犯感建立气势，但站内写作不能靠贬低不同行为的人来显得鲜活。可以保留"我选择这种生活"的锋利，也可以写出"这种生活不适合所有人"的边界；不要把没这样生活的人写成怯懦、无趣或低等。
- **把清单写成连续场景**：生活升级类素材很容易退化成条目。真正能留下来的写法，是每一条背后都有一个可见场景：谁在场、手做了什么、声音从哪里来、身体有什么反应、这个选择如何改变接下来的一小时。没有场景的建议，再刺激也只是口号。
- **保留异质细节，过滤危险结论**：原始素材里常有能点亮文章的异质细节，例如粗粝的作家、宗教文本、海风、招牌饮品、异乡住所、特定衣料、陌生人的姿态。可以吸收这些细节带来的质感，但不要吸收不可靠的健康建议、性别刻板印象、成瘾合理化或把冒险包装成必然正确的判断。
- **让读者想活一次，不要逼读者照做**：这类文章的目标是让一种经验变得可感。读者读完后可能想去海边走走、翻开一本书、换一件衣服、重新布置房间，也可能只是更清楚自己不想要什么。散文做到这里就够了，不需要把私人体验推成普遍处方。

## 结尾

- **结尾停在画面**：不要收束到结论、感悟、号召。让最后一幕是一个具体的场景——一个动作、一处风景、一句未说完的话。
- **远景比近景更稳**：用持续性的、远景的动作收尾，比近景特写更收得住——"汉江的水在暮色里缓缓向前流去，远处的桥还亮着灯"，江水是持续动作、灯还亮着是未完的状态。不要用一碗汤、一个杯子、一张脸的特写收尾。
- **结尾一旦定下远景，不要让镜头再回拉近景**：远景已经开始走（江水在流、灯还亮着），就不要再让镜头回到手里那杯咖啡、桌上那碗汤、脸上那道光。"拉面凉了、杯壁挂着水珠" 这种近景特写会打断已经定下的收束节奏，直接删。

## 检验清单

每篇成稿前过一遍：

- 这件事真实吗？
- 有没有具体细节？
- 有没有具体的人？
- 有没有具体场景？
- 思想是不是最后才出现？
- 有没有直接说教？
- 主题是否只有一个？
- 能否删掉一半观点？
- 是否写出了我自己？
- 结尾有没有留白？
- 每个场景里有没有一个具体的"别人"，而不只是叙述者？
- 有没有把"看了一眼"换成具体的微动作？
- 同一地点有没有从多个尺度（上下、里外、远近）观察？
- 生活方式素材有没有写出场景、身体反应和代价，而不是只留下刺激性建议？
- 有没有把冒犯、成瘾合理化、性别刻板印象或危险行为当成可沉淀原则？
- 结尾用的是远景+持续动作，还是近景特写？
- 有没有出现工程语/工作日志黑话？（品牌名是场景锚点，保留）
- 有没有点明"第一天/第二天/最后一天"？
- 一段是不是只围绕一个核心观察展开？
- 结尾的镜头有没有回拉到近景特写？
