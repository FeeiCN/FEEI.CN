音乐统一由 `src/theme/Root.tsx` 挂载的 `GlobalMusicPlayer/Client.tsx` 播放。顶部导航右侧的 `GlobalMusicPlayer/NavbarButton.tsx` 提供音乐入口，`GlobalMusicPlayer/Controls.tsx` 提供选歌面板及手机播放后的底部迷你条，`MusicLibrary` 仅作为面板内部按需加载的选歌组件，不再单独发布音乐库页面。歌曲数据仍在 `src/components/GlobalMusicPlayer/playlist.ts`，不要建立第二套播放器或重复歌单数据。

`/my-playlist` 保留为兼容入口，转到首页并打开选歌面板。任意站内页面使用 `?music=open` 可打开面板；打开面板不自动播放，点选歌曲后才播放。文章内 `MusicTrackPlayer` 继续通过事件控制同一个播放器。原生播放列表按钮也打开这个选歌面板，全屏歌词由用户主动打开。

选歌面板在当前标签页的会话中保留歌单、歌手、搜索词和滚动位置，收起窗口、展开或收起播放控制、换页及刷新后均可恢复。歌单选择器仅展示常用歌单与分类，歌手使用独立的搜索筛选；曲名搜索覆盖全库。“定位当前歌曲”会清除筛选，切到歌曲所属歌单并滚动至当前曲目，不重新播放歌曲。

窗口默认展示选歌列表，不使用顶部切换页签。搜索独占一行，歌单和歌手筛选并排一行，统计和当前歌曲定位放在列表上方；歌曲按歌单顺序展示歌名与歌手。播放后的当前歌曲固定在窗口底部，可暂停或切换下一首，点击歌曲信息在底部原地展开进度、播放控制和辅助工具，再次点击收起。歌单始终保留，不切换详情页面，也不重新挂载列表；展开状态通过箭头及 `aria-expanded` 表达。

顶部入口、迷你条和当前歌曲区域共用加载中、播放中、已暂停及加载失败的状态。顶部悬停提示包含歌名和歌手；迷你条加载失败时可直接重试。当前歌曲使用紧凑封面与歌名、歌手标识，展开后依次展示进度、上一首／播放／下一首，以及顺序、循环、音量和歌词工具；紧凑状态保留暂停与下一首，避免重复展示主控制。展开与收起使用 Chakra Collapsible，并遵循减少动态效果的系统设置。音量使用独立弹层。窗口使用站点强调色，长歌名最多展示两行并保留完整文字提示。

## 音频文件

所有音频文件统一放在 `static/music/` 下。

- 文件命名：`歌名-歌手.扩展名`，例如 `大海-张雨生.flac`、`MineMine.wav`。
- 周杰伦专辑类放到 `static/music/周杰伦/`，playlist 注册时保留子目录前缀，例如 `周杰伦/一路向北.wav`。
- 扩展名支持 `mp3` / `wav` / `flac`，URL 通过 `toEncodedUrl` 编码，并统一生成 `https://feei.cn/music/...` 完整地址。
- 不直接引用其他站点的音频，文件先本地化；播放器请求本站共享音频目录的完整地址，不将大文件加入 Git。

## playlist 注册

`playlist.ts` 的三个基础分组继续保留：`favoriteTracks`（我喜欢的音乐）、`jayTracks`（周杰伦）、`ambientTracks`（白噪音）。宝宝音乐从 `https://feei.cn/music/baby-music/manifest.json` 按需载入，筛选和歌手分组由现有工具函数派生。

在对应分组末尾追加 `localTrack('歌名', '歌手', '文件名')`，函数根据 `localLyricsFileByAudioFile` 自动挂载歌词：

```ts
localTrack('大海', '张雨生', '大海-张雨生.flac'),
```

## 歌手归属与字段一致性

- 合作歌手用 `&` 分隔，例如 `'周杰伦 & 费玉清'`。
- `primaryArtistOf` 取主要歌手归一，避免合作版本产生重复歌手条目。
- 同一首歌不要在多个基础分组重复注册；KTV 等维度使用派生筛选分组。
- 不同版本（live/remix/cover）可以独立注册，文件名后缀区分。

## 歌词映射

`src/components/GlobalMusicPlayer/localLyrics.ts` 由脚本生成，不手工编辑。添加音频后运行：

```bash
python3 scripts/download_music_lyrics.py
```

## 添加与删除

添加单曲时，先放好音频，在 playlist 注册，再生成歌词映射。删除时同步移除 playlist 条目、音频及对应歌词，并重新运行映射脚本，避免留下失效引用。

## 验证与发布

本地运行 `npm run start`，在任意页面打开顶部导航右侧的音乐按钮，检查搜索、歌单和歌手选择、点选播放、暂停收起、进度恢复、换页连续播放和主动切换全屏歌词。桌面面板位于顶部入口下方，再点入口可收起；收起后仅保留顶部入口与播放状态，不显示另一份底部窗口，也不为其增加正文底部留白。手机使用底部对话框，锁定背景滚动并约束键盘焦点；仅在手机宽度（不超过 640px）播放后显示底部迷你条，可暂停、切歌或切回面板。未播放时不显示迷你条及当前歌曲底栏；手机停止播放并收起会暂停音频、隐藏迷你条。顶部图标显示播放和展开状态。验证收起面板后焦点回到入口按钮，`/my-playlist` 与 `?music=open` 都能打开面板且不会自动播放。桌面和手机宽度都要检查溢出、滚动和关闭入口。

遵循仓库构建与发布流程。音乐组件相关 PR 通过 `music-player-check.yml` 执行类型检查、文档检查、构建及浏览器回归；浏览器测试使用生成的音频夹具，不替代上线后对真实音频文件的检查。

调整选歌交互后，检查会话恢复、歌手搜索、当前歌曲定位、播放控制原地展开收起、列表滚动位置和手机弹层焦点；调整状态反馈后，用音频请求失败及延迟场景验证重试、加载、暂停与播放状态。检查音量弹层的键盘操作、长歌名、小屏幕上的进度条和主要播放按钮，以及深浅主题。
