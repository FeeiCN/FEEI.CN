# 日本的人，国内的系统

09-07 · 星期一

早上七点从札幌出发赶往新千岁机场，坐到飞机最后一排，一路困得不行。十一点多落地成田，本来还惦记着去看看东京的灯红酒绿，结果坐上一趟慢得让人怀疑人生的车。到了千叶，再看一眼地图，去池袋还得一个小时。

算了。

于是留在千叶吃了一碗神座拉面，又去奥特莱斯闲逛。意外买到一双 Nike 和三条 Levi's，尤其难得的是裤子居然都能穿。几件东西加起来一千多一点，而同行有人一条裤子就九千多。消费观这种东西，放在一起才发现差得真远。

这趟日本还有个感受很难忽略：服务是真的好。商店、餐厅、交通，很多时候只是一些很小的动作和语气，却会让人觉得自己被认真对待。这种感觉回国以后并不总能遇到。

返机场的车等了五十分钟。到了机场想再吃一碗拉面，队又太长，最后在 7-Eleven 买了铜锣烧和一些小吃。晚上九点，大雨，飞机倒准时起飞。旁边的人一路絮絮叨叨，降噪耳机都压不住。

没想到最后还提前到了杭州。十一点落地，十一点半已经坐上网约车。

顺手记下一条以后肯定还会用到的经验：萧山机场 T4 打网约车，小号电梯附近更方便；国际到达过完海关就可以开始叫，国内到达等到行李提取处再叫差不多。

每次从国外回来，都会突然重新发现国内生活的方便。网络、支付、打车、外卖，一落地就重新连在一起。

日本的人对人的服务很好。

国内的系统对人很好。
