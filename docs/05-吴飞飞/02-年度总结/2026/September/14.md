# 三箱苹果

09-14 · 星期一

老婆今天正式回去上班了。产后休息了几个月，真正重新开始工作的这一天还是来得挺快。换成是我这么久没上班，再坐回工位，大概还得适应一阵子。

我这边依旧不到八点就起床，从延安出发去黄帝陵。

陵区最先让我停下来看了很久的，不是建筑，而是那些古柏。很多树已经活了上千年，树干粗壮扭曲，枝杈的形状也和日常见到的树很不一样。黄帝陵祭祀黄帝的历史绵延很久，站在这样的地方，“几千年”原本很抽象，看到这些仍然活着的树，突然就具体了一点。

午饭又是满满一大桌菜。这几天的正餐几乎顿顿像吃席，丰盛是丰盛，却总觉得少了点陕西的味道。来陕西这么多天，我居然还没正经吃过一碗面。吃饭的时候还想着，走之前怎么也得找机会尝尝。

下午去了洛川摘苹果。这也是我第一次真正看到苹果树。

树不高，枝头却密密麻麻全是苹果，有些枝条已经被果子压得弯下来。站在果园里会很直接地感受到“丰收”两个字是什么样子。刚摘下来的苹果酸甜、脆口，不过我还是更喜欢面的。

摘了几个，第一反应是带回去给家里人尝尝。

旁边一个同事看了看，问我：“你买这么点，够给同事分吗？”

我愣了一下。

因为我根本没想过同事。这些苹果就是给家里人摘的。

以前有同事说过我没什么“江湖气”，和大家不够亲近。当时听到了，但没有太往心里去。今天突然发现，这可能根本不是什么抽象的性格问题，而是藏在这种很小的下意识里：去了一个地方，我自然会想到老婆、孩子、家里人，却从来没有形成“给同事也带点什么”的习惯。每天和大家一起工作，工作之外的交情确实不多。

于是拿出手机，给团队下单了一箱。

过了一会儿又想起来：成都的同学呢？

又补了一箱。

冯导在旁边说，我既然喜欢面的苹果，可以试试甘肃天水的黄元帅。听完又下单一箱，留着自己吃。

到了机场，大家终于去吃面和肉夹馍了。

偏偏这时候我一点都不饿。

来陕西几天，顿顿大桌菜，最后直到上飞机，也没吃上一碗陕西面。

飞回杭州的路上，把 META 全卖了，又补了一些 VGT。前几天才在回酒店的车上看着两个账户，一个指数涨了二十多个点，一个个股账户折腾半天还在原地，现在算是又往前挪了一步。

晚上九点多落地杭州。走到行李转盘时叫了车，拿完行李一路到 K2，车也刚好开到。

时间卡得严丝合缝。

这趟延安最后带回来的，是几个自己从树上摘下来的苹果。

另外三箱，已经在去往不同地方的路上。
