订好了明天去上海的动车和酒店，也把 Visit Japan Web 的入境审查表单填了。

没来得及买专门的电话卡，就在电信平台上订了个99元的日本四日漫游流量套餐。后来在日本使用时才发现，地图经常在 GPS 信号不好的地方定不到位置，有时甚至把我定位回国内。我怀疑和漫游流量从国内出口有关，这次用起来不太合适。

老婆今天用拼豆拼了个西瓜，还蛮像实物的。

晚上骑小电驴回家，虽然有雨衣，雨水还是进来了。好久没淋过雨了，倒觉得挺舒服。

老婆晚上帮忙准备了下行李。现在不管去哪里，只要是几天的行程，背一个包就够了，非常方便。
