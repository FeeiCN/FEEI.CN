# 五点的上海街头

09-04 · 星期五

四点多就起床了，坐上酒店五点的送机依维柯。天已经一点点亮起来，这是第一次看到清晨五点的上海街头。平时拥挤的城市还没完全醒，路上几乎没什么人，六点就顺利过了安检。

来得有点早，结果飞机又延误了一个小时。

这种团队旅行好像总少不了一点关于护照的插曲。去年有人交了钱最后没来，也有人到了出发那天才发现没带护照，只能第二天再赶过来。今年居然又续上了：一个同事临时因为工作没法来；去年那个忘带护照的同事这次倒是记得带了，只不过——带错了护照。

到了札幌新千岁机场，等大巴来接我们。一路往登别走，饿得不行，中途找了一家店吃了碗荞麦面和一份天妇罗。面还不错，天妇罗亮晶晶的，油得有些过头。

到了酒店，放下东西就去了地狱谷。一下车就闻到一股很明显的臭鸡蛋味，小山坳里零零散散冒着白色热气，空气里都是温泉区特有的硫磺气息。找到一处可以泡脚的地方坐下来，把脚伸进水里，水摸起来有些滑滑的。

晚上去了附近另一家温泉酒店吃自助餐，东西比较一般。回来的路上正好碰到当地的鬼怪表演，倒给这个温泉小镇添了一点奇怪又热闹的气氛。

回到酒店，他们还准备继续去泡温泉。我还是接受不了一群人坦诚相见这件事，于是作罢。

晚上睡的是榻榻米。房间不大，睡觉前要先把桌子挪开，再在榻榻米上铺床垫。厕所也小得有些拥挤。坐在这样一个北海道乡下的小房间里，我突然有点疑惑：登别都已经这么偏了，土地总该没那么紧张了，怎么房间还是做得这么小。

从凌晨四点起床，到晚上躺在榻榻米上，一天像是被拉得很长。五点的上海街头、带错的护照、机场、荞麦面、地狱谷的热气和硫磺味，最后都挤进了这间小小的日式房间里。
