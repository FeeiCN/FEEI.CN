# 还行的最好不要

09-08 · 星期二

昨晚刚从日本回来，早上困得厉害，干脆休了一天假。

没有急着安排什么，在家陪宝宝。周五又要去延安，这几天待在家的时间一下显得很短。

休假也没完全离开工作，临时处理了一件监管检查相关的事。AI 中转站也开始频繁出现 overload，原本已经用顺手的东西突然变得不稳定。

之前一直舍不得买的徕芬 LF03，最后还是花四百多下了单。每天早上头发都要吹很久，这次决定不再和这几分钟较劲。

本来还准备去医院查维生素 D，临时约不到号，只好改到第二天去西溪医院。

下午和老婆去了临平奥特莱斯。前一天在日本刚买完衣服，今天又试了一圈，最后带回两件 Nike、两件 GAP、一双 Adidas 鞋和一件外套。

试来试去，倒确认了一个挺朴素的标准：

**还行的最好不要。**

买衣服是这样，招人好像也是。
