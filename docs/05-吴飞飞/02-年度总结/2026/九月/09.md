# 五六管血

09-09 · 星期三

本来只是想去西溪医院查个维生素 D，结果医生一开口，检查单越来越长。

情绪低落可能和很多东西有关：维生素 D、胰岛素、皮质醇、甲状腺……最后抽了五六管血，三百多块。偏偏抽血前还不小心喝了一口奶，多少有点犯嘀咕。抽完以后索性把剩下的奶和一个鸡蛋吃掉，中午没吃，晚上两个包子、两个茶叶蛋和一瓶奶。

前一天担心的监管检查重新对了一遍，最后确认和我没什么直接关系，倒是把明年检查前要提前准备的事情梳理了一次。今年国家网络安全宣传周的行程也定了，数据安全几个人的 OKR 重新过了一遍，晚上又面试了一个人。

徕芬吹风机也到了。

之前舍不得买，真买回来以后，老婆发现拼多多更便宜，于是又退掉，她重新买了一台。

一个吹风机，来回折腾了两遍。

AI 中转站则开始真正让人头疼。服务器过载提示越来越频繁，到底是新模型上线后资源紧张，还是 OpenAI 同时加强了对中转站的识别和风控，当时还说不准。
