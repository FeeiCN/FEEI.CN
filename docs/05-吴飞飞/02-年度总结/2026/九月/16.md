# 趵突泉和大明湖还在旁边

09-16 · 星期三

早上不到八点起床，饭都没来得及吃，就出发去山东国际会展中心。登记、领证、进场，时间刚刚好。今年明显比往年人多，感觉可能有两倍以上。看了眼议程，一上午十几个主题演讲，我先把最后三家明显卖货的排除了。没想到第一个上台的，也是卖货的……

中午和腾讯的朋友又去了昨天那家湘菜馆，金钱蛋、腊肉之类点了五个菜，又吃到了十分饱。最近总说七分饱，到了湘菜馆还是很难执行。

下午回酒店，主要在研究整理三十多篇安全法律法规，一篇篇看要求怎么解读、实际应该怎么落实，以及最后怎么验收。本来想着既然来了济南，旁边的趵突泉和大明湖总该去看看，但人有点疲惫，没什么精神，最后还是留在了酒店。

晚上打开闪购翻了一圈商家，越翻越觉得山东好像真没啥想吃的，最后点了份海底捞冒菜，这次收在八分饱。来了这几天，对这里最直接的印象反而不是某个景点：城市有些灰蒙蒙的，建筑看起来偏老旧，街边店铺里吃的特别多。接触下来也感觉这里的人说话做事普遍急一些。

一天结束，趵突泉和大明湖还在旁边，没去。
