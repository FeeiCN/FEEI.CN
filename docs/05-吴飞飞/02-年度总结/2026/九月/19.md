# 两年前像几个月前

09-19 · 星期六

中午和老婆、新民一起去西天目山。

我印象里几个月前才和新民来爬过一次，结果翻了下记录，居然已经是两年前了。脑子里的“前不久”和真实时间差了这么多，还是有点恍惚。两年好像也没发生多久。

到了以后又碰上文旅卡的问题。人才码里的文旅卡过期了，重新领取以后还要两个小时才能生效。好在门口保安大叔比较通情，让我们先过去了。

结果没走多久，又碰到一道门，说继续往上要交 110 块钱，而且两点以后就不让上山，说现在上去也来不及了。

就有点莫名其妙。

文旅卡上明明写着西天目山免费，到了里面怎么又要单独收 110，而且还这么贵。罢了，也没继续折腾，临时找了个蝴蝶谷。等走回停车的地方一看，已经走了一个小时，姑且算今天的热身。

开了半个多小时到了蝴蝶谷。

这里反而比原计划更合适。徒步小路基本沿着河谷走，一路有很多地方可以直接下到溪水里，特别适合溯溪。我赶紧把溯溪鞋换上。

不知道是今天降温，还是九月真的开始凉了，溪水已经有点冰。水非常清，里面还能看到很多小鱼。路上人也不多，我们就沿着小溪一路往上游走。

中间找到一个挺深的水洼，我看着特别想下去洗个澡。试了下水温，实在太冷，遂罢。

最后找了一块溪边的石头坐下来，把脚伸进水里，吃瓜子和零食，再捧点溪水洗洗脸，反而特别舒服。

当时就开始想，下次完全可以带个天幕和垫子，在树荫下面找块平整的石头躺着，再往水里放个西瓜。

巴适得很。

快五点的时候已经有点晚了，我们也没再继续往里走。这里本来就不是景区，路不算好走，真等到天黑再往回撤还是有点危险。于是开始回程。

下次可以早点来，按自己想要的样子准备好，再慢慢待一下午。

回程的时候，看到夕阳落在大片麦田上，整片地都被照亮了。那个画面特别像小时候家乡的感觉，一下子有点像回去了。

今天还顺手把博客播放器的界面设计和交互重新优化了一遍。之前按钮太小，平时用还好，但开车的时候就很不方便。现在把常用操作重新做得更适合车上使用，顺手多了。

就是 Codex 还是慢得有点离谱。动不动几十分钟，甚至一两个小时。

这个问题得认真排查一下了。
