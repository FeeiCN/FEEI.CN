# 09-21 · 星期一

早上八点多就到公司，听宫玉振老师分享《古田会议的背景、内容和意义》。老师的声音有点浑浊，听起来有些吃力。大致讲的是红军早期在事业和组织陷入低谷时，如何突破困境，不少地方让我想到今天企业遇到的情况。

今天把相关思考整理成了[《如何获得广泛支持》](/how-to-gain-broad-support)。研究问题、提出方案，是我比较熟悉的路径；别人为什么愿意一起做，他们要承担什么成本，过去想得少了一些。

下午和团队同学去茶园喝茶、散步。仲希安排得很周到，准备了蛋糕，还送了一个给宝宝做辅食的锅，说特别好用。

自己居然34岁了，真的要过35岁这个坎了。昨天面了五个人，四个校招、一个社招，都很优秀，借助 AI 都能把事情做得很不错。说实话，还是有点危机感。

下午还收到了全员邮件，说数字互联、数字支付、芝麻信用要合并，由 CPO 担任总裁，原先数字支付的联席总裁担任副 CPO。去年拆的，今年又要合并。

这几个 BG，尤其数字互联和数字支付，分工协同确实有不少问题，有一个共同老板来管，我觉得会好很多。和网络安全、数据安全一样，紧密关联的事情很难各管一段。不过，业务真正的下一个爆点在哪里，还是组织调整之外更大的问题。

从茶园出来，村子里的路实在太窄，小鹏 GX 又太宽。老司机也得小心翼翼，才把车开出来。
