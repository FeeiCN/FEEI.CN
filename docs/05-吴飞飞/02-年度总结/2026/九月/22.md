# 09-22 · 星期二

早上有位同学做试用期答辩。新同学一般都有基础技术能力，但进来以后，为什么做一件事、具体怎么做、怎么和别人配合、做到什么程度，还是需要有人带着弄清楚。不然做了很多事，回头看，却不一定是企业真正需要的。下午面了一位还不错的同学，整体感觉比较踏实。现在招人，我更希望找到稳定、踏实的人。

晚上对了一下 AI 原生研发流程里安全 Agent 的设计，最终整体研发流程也用 multica 来实现了。之前做安全的“蚁窝”，做着做着就发现和 multica 非常像，而且人家更成熟，Agent 协作和过程观测都做得更好。当时就觉得，应该把蚁窝迁过去。

今天晚上还有飞盘比赛。我们管理队对上了真刀真枪打出来的冠军组。人家都放水了，我们居然还是差点输了。比赛前后也就十来分钟，已经满身大汗，运动效果倒是很好。
