# 09-24 · 星期四

昨天晚饭时还能下床走动，早上醒来又不行了。左脚的痛点从脚踝挪到了小脚趾附近，疼的地方换了，还是站不起来。安排好工作，请了假，又在床上躺了一天。

给博客做了些优化，也看了《年会不能停2》。没第一部好看，不过作为喜剧还行。后来把电视剧《神话》开着当背景，倒又开始琢磨刘邦、朱元璋、毛泽东这些人的经历：起初看着没多少优势，怎么后来一步步改变了局面？

顺着这个问题，整理了一篇[《后来者的优势》](/resource-poor-rise)。比起最后怎么赢，更想弄清楚最初那一点优势，怎么能在一次次做事的过程中留下来，而不是每次都从头开始。
