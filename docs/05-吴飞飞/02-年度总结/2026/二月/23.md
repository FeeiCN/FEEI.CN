睡眠评分高（84分），醒来8次12分钟，晚睡一个小时，主要因为看太平年看到了关键剧情，胡进思让钱弘棕让位于钱弘俶。

体重145，下降0.6。

- 早饭，两个鸡蛋🥚一瓶牛奶🥛。
- 午饭，牛排🥩芋头蔬菜🥬。
- 下午，在家一天，剩下的零食吃了，下次零食不能放在眼前，禁不住诱惑。本打算下午开完会，看完《乡村爱情18》24集，去西湖跑个步。但天气阴下来了，这种天气还要20分钟，就作罢了。
- 晚饭，辣子鸡丁、酸菜白肉炖粉条。
- 晚上，划船30分钟，542米，平均心率126。按照全力划一分钟再歇一分钟模式，效率和可持续更高。
- 今日心理状态，有点愉快。看着确实瘦了很多，整个人精神很多，皮肤好像也好了点。

见识乡村爱情中的父母辈关系才能体会当前的幸福。看到李文才的女婿、谢广坤的儿媳，虽是演绎，但从农村出来的我也深知这些都是来自于生活，摊上这些岳父母得多么可怕，对比下自己的岳父母，每天做好各种花样的饭菜，各种水果，家务事全都承担，照顾情绪，简直天壤之别。

X上不断冒出让人焦虑的AI FOMO。白领大规模离职也许还早，但一直被动追逐新概念并不会让人真正靠近AI。比起把每个工具都学一遍，更应该练习判断、承担责任、建立信任，以及把想法做成结果。

最近AI对SaaS软件股冲击确实很强，虽然有点过度了，不过确认让人考虑原先定投指数的路径好像不那么成立了。需要更聚焦押注在更有信心的特斯拉上。

手机写写日记还挺方便，但要沉淀总结其它内容时并不方便，现在是记录在日记或者备忘录中，待统一在电脑上整理。由于主力电脑在书房，太重工作氛围了，自己又很多时候都在主卧阳台待着，需要一台轻便的电脑，来研究和整理体系内容。本打算用老婆那台退役自购工作MacBook Air电脑，太老了，都六年多了（看了下自己主力机居然也五年了，不过当时买的顶配，现在还很强），还是i5处理器，用了下性能太差了。打算买一台新款MacBook Air，价格挺便宜，官网7999，京东优惠下来5200。看了下评测，对颜色有点纠结，首先排除银色和深空灰，太像工作电脑了。天蓝色、午夜色、星光色都还不错，明天路过印象城去看看实物。
阴天让跑步计划停在家里，划船机却把三十分钟完整划完；阳台上的FOMO也暂时安静了。
