今天在家待了一天。上午天很蓝，天气挺不错，本来还想出去转转，但健康数据同步的问题还比较多，最后还是留了下来。

下午索性把这套流程重构了一下，把健康数据从 Git 里剥离出来。改成从手机获取全部健康数据后，直接推送到服务器，再由程序处理需要的部分。这次不是继续调整数据在 Git 里怎么存，而是换了一条同步和处理的路径。

老婆他们下午去了闲林水库，没多久就下雨了。上午还那么蓝的天，下午就变了。
