今天立冬，下着小雨，没有外出，在家待了一天。现在每天老婆早早起来，把珠珠带上来，让她喊我起床，效果还挺不错。

老妈去楼下买了个拌面。拌面还是得现场吃，拿回来吃，感觉完全不一样。中午江茂源和他妈来看宝宝，岳父做了一桌子菜。他们吃完没多久就走了。

可能是昨晚回来得太晚，中午有点困，想睡一会儿。好像最近经常这样。定了一个小时的闹钟，结果一觉醒来，已经下午五点了……

睡完确实精神了很多，又研究了下 ontology（本体），以及怎么把 GitHub Actions 和大语言模型结合成工作流，用来提升个人能力、完善网站内容。

新的 MacBook Air 键盘上，数字键「3」出了点问题，按下去没有清晰的按键感，像是被什么卡住了。下次去苹果店，带过去修一下。
