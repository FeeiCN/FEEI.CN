昨晚手表充电，忘了戴回去。早上不到八点就起来了，上完厕所还有点困，又回去补了一会儿觉，九点多才出门。

今天研究了一下信息安全技术相关的三百多篇标准文档。

先让 AI 找到标准网站，检索目前仍然有效的信息安全技术标准，再把对应的 PDF 下载下来。原本想直接提取文字，结果效果不太好，于是又让 Agent 写了个调用 macOS Vision 的程序，通过视觉识别把 PDF 转成 Markdown。

光提取还不够，又通过 PDF 页面截图，让多模态模型和提取后的文字逐一比对，发现差异就修正，需要的截图也自动补充进去。

整个过程基本就是给出一句话，让 Agent 自己持续运行了几个小时，直到把三百多篇标准全部整理好。

有 Agent 确实方便。以前做这件事，估计得花好几个星期，现在几个小时就能完成。

又盘点了招聘情况，进展还挺不错的。目前已经入职两个人，还有几个在最终流程中。智能工程、检查和人机专项的进展也都还好。

中午吃的健康餐，晚上和仲希一起吃蒸菜，也挺健康的。

今天岳父回杭州了，还带了我喜欢吃的豆干和辣牛肉。

今天在支付宝财富看到一个弹窗，发现有投资纳斯达克 100 和标普 500 的私募产品，门槛分别是 50 万和 100 万。

一直在考虑怎么让资金不出境，也能长期投资这些指数。现在看到有这样的产品，打算挪点钱过去投一下。

晚上美股又跌了，顺手加仓了一点 VGT。
